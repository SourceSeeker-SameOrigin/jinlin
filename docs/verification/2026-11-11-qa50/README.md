## 完成与边界

- 支付成功停留paid，不向住户提前发送accepted/delivered。新任务提醒保留。
- 服务员接单、管理员指派条件更新成功后才通知；冲突、重复接单/支付不重复通知。
- 真实notify模块的发送错误被捕获，订单不因通知失败回滚；缺模板跳过。
- 完成服务后发delivered，重复完成不重复发送。
- 不增加通知重试任务或新的消息持久化机制；状态提交后进程退出造成通知遗漏，仍属现有尽力发送边界，不声称可靠消息全链路完成。
- 云端尚未部署，实际模板、一次性授权及手机收到消息未验。
