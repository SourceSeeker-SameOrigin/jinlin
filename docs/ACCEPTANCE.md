1. 先解锁 Mac；在微信开发者工具确认项目仍使用开发环境 `cloud1-d4gbpd8zx89564fb6`。
2. 按 `docs/MANUAL_SETUP.md` 创建集合、导入种子、建立索引和安全规则，再部署云函数。
3. 准备住户、物业、管理员、level 1 服务员、level 2 服务员账号；手机号和相机权限在真机确认。
4. 先用 mock 模式执行核心场景。真实微信支付、退款和商户设置单独验收，过程中不进行真实扣款，除非用户另行授权。
